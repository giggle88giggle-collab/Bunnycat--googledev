Privacy Policy – Bunny & Cat YouTube Tool

Effective date: 22 October 2026. Operator: Bunny & Cat Studio, www.bunnycatstudio.online ("we"). This policy covers only the YouTube upload tool. The games' policy is at /privacy-policy.html.

1. What the tool does

The tool creates short educational videos and uploads them to the studio's own YouTube channel. Uploads are set to private. The studio owner decides separately whether any video is made public.

2. Google user data we access

The studio owner signs in with Google and grants two permissions (OAuth scopes):

  • https://www.googleapis.com/auth/youtube.upload – to upload videos to the studio's channel.
  • https://www.googleapis.com/auth/youtube.readonly – to read back the status of uploaded videos and confirm they are private.

We store a refresh token so the tool can obtain short-lived access tokens without a new sign-in. Access tokens are used only for the request they are obtained for and are not stored.

3. How data is stored and protected

  • The refresh token is encrypted with a separate key. The encrypted token and key are kept as encrypted secrets in a private GitHub repository. They are never published, shared in chat, or written into code or logs.
  • The publish log records, for each video, the title, episode name, upload result, and YouTube video ID and link. It is kept in the same private repository.
  • No refresh token or access token is sent to a web browser.

4. How we use the data

We use Google user data only to upload and verify videos on the studio's own channel, and to show the owner the upload status and any reconnection message. We do not sell Google user data. We do not use it for advertising, profiling, or training AI or machine-learning models. We do not share it with third parties except as described in section 6.

Use of information received from Google APIs complies with the Google API Services User Data Policy, including its Limited Use requirements.

5. Children

The channel makes content for young children. This tool does not collect personal information from viewers or children, and this page uses no cookies, analytics or advertising.

6. Third-party services

  • Google / YouTube – sign-in and video uploads. Governed by Google's privacy policy.
  • GitHub – hosts the code, runs the scheduled jobs, and stores the encrypted secrets.
  • Microsoft Edge text-to-speech – the narration script text is sent to Microsoft's speech service to create voice audio. No Google user data is sent to it.

7. Retention and deletion

  • The refresh token is kept until it is revoked or the stored secret is deleted.
  • To remove the tool's access, the studio can remove "Bunny & Cat" at myaccount.google.com/permissions and delete the GitHub secrets. Access then stops immediately.
  • Uploaded videos stay on YouTube until the studio removes them there.

8. Your choices and contact

You can revoke access at any time (section 7). Questions: support@bunnycatstudio.online.

9. Changes

If this policy changes, the new version is posted here with a new effective date.
